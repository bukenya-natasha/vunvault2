Security Advisory

Active threat advisory: internet-exposed control systems

We publish short, practical advisories when real-world attacks teach us something every organization should know.

VUNVAULT-ADV-2026-0803-01
Severity: Critical Active Campaign ICS / OT Sector

Why this matters, in plain English

A PLC is a small industrial computer that tells pumps, valves and sensors what to do. When left connected to the internet with factory default passwords, an attacker can find it in minutes and take control.

Seven mitigations we recommend
  1. Audit every PLC, HMI, SCADA interface. If it does not need to be online, take it offline now.
  2. Change default credentials immediately and enforce MFA on workstations and HMIs.
  3. Require VPN-only remote access from allow-listed IPs. Never expose control systems directly.
  4. Segment OT from IT and block unexpected outbound traffic from control systems.
  5. Monitor for password or IP changes on controllers, devices dropping offline, odd-hour logins.
  6. Back up controller logic and rehearse manual operation.
  7. Test your own exposure with an authorized attack-surface assessment.
